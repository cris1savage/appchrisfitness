# appchrisfitness

- `/` — panel web (Next.js + Supabase): coach en el ordenador, clientes en el móvil (instalable como app)
- `mobile/` — app iOS y Android (Expo) sobre el mismo Supabase. Ver `mobile/README.md`
- **[LANZAMIENTO.md](LANZAMIENTO.md)** — pasos para publicar web y app

## Web en local

```bash
cp .env.example .env.local   # rellena los valores de Supabase
npm install
npm run dev
```
